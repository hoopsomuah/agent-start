# Getting Started with CopilotVSCode

Welcome to CopilotVSCode! This guide will help you get started with coding using our pre-configured environment.

## What is CopilotVSCode?

CopilotVSCode is a ready-to-use coding environment that combines:

- **Visual Studio Code** - A powerful, free code editor
- **GitHub Copilot** - An AI assistant that helps you write code
- **Pre-configured settings** - Everything set up for the best experience

## Installation

### Option 1: Download Ready-to-Run (Recommended)

1. Go to the [Releases](../../releases) page
2. Download `CopilotVSCode.exe`
3. Double-click to run
4. Start coding!

### Option 2: Build from Source

```bash
# Clone the repository
git clone https://github.com/hoopsomuah/agent-start.git
cd agent-start

# Install dependencies
npm install

# Build
npm run build
```

## First Steps

### 1. Open CopilotVSCode

Double-click the executable. A clean, beautiful editor will open.

### 2. Create Your First File

- Press `Ctrl+N` to create a new file
- Press `Ctrl+S` to save it (choose a name like `hello.py` or `hello.js`)

### 3. Write Some Code

Start typing! For example, try typing:

```python
# A simple Python greeting
def greet(name):
```

Watch as GitHub Copilot suggests the rest of the code!

### 4. Accept AI Suggestions

- When you see gray suggestion text, press `Tab` to accept it
- Press `Ctrl+I` to ask Copilot for more suggestions
- Press `Ctrl+Shift+I` to open Copilot Chat for questions

## Tips for Beginners

### Let AI Help You

- **Write comments first**: Describe what you want in a comment, then let Copilot write the code
- **Ask questions**: Use Copilot Chat (`Ctrl+Shift+I`) to ask "How do I...?" questions
- **Learn from suggestions**: Read the suggestions to learn new coding patterns

### Stay Organized

- **Create folders**: Right-click in the file explorer to create new folders
- **Use meaningful names**: Name your files and folders clearly

### Don't Worry About Mistakes

- **Auto-save is on**: Your work is automatically saved
- **Undo is your friend**: Press `Ctrl+Z` to undo any mistake
- **Experiment freely**: You can always start over

## Getting Help

- **In-app**: Press `Ctrl+Shift+I` to open Copilot Chat and ask questions
- **Documentation**: Check the [docs](./docs) folder for more guides
- **Issues**: Report problems on [GitHub Issues](../../issues)
